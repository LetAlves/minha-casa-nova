# Como instalar e rodar o app

## Passo 1 — Instalar o Node.js
1. Acesse: https://nodejs.org
2. Baixe a versão **LTS** (a recomendada)
3. Execute o instalador e clique em Next em tudo
4. Reinicie o computador após instalar

## Passo 2 — Instalar o Expo Go no celular
- **Android**: baixe "Expo Go" na Play Store
- **iPhone**: baixe "Expo Go" na App Store

## Passo 3 — Abrir o terminal nessa pasta
1. Abra o Explorer e navegue até esta pasta (minha-casa-nova)
2. Clique na barra de endereço do Explorer
3. Digite `cmd` e pressione Enter
4. O terminal vai abrir já nessa pasta

## Passo 4 — Instalar as dependências
No terminal, cole este comando e pressione Enter:
```
npm install
```
Aguarde terminar (pode levar alguns minutos na primeira vez).

## Passo 5 — Rodar o app
```
npx expo start
```
Um QR Code vai aparecer no terminal.

## Passo 6 — Abrir no celular
- **Android**: abra o app Expo Go → escaneie o QR Code com a câmera
- **iPhone**: escaneie o QR Code com a câmera nativa

O app vai abrir no seu celular! 🎉

---
Obs: o computador e o celular precisam estar na **mesma rede Wi-Fi**.
